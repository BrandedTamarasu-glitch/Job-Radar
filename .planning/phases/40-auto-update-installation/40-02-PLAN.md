  <name>Task 2: Wire install flow into MainWindow with confirmation, launch, and exit</name>
  <files>job_radar/gui/main_window.py</files>
  <action>
Implement the complete install-after-download flow in MainWindow.

**Add imports at top:**
- `import sys` (if not already imported)
- `from job_radar.update_checker import launch_installer, cleanup_old_installers`
- `from job_radar.gui.installer_dialogs import InstallConfirmDialog, LinuxInstallInstructionsDialog`

**Add `_on_install_now(self, dest_path: str)` method:**

This is the callback wired to the banner's Install Now / Open Download button.

1. Store `self._installer_path = Path(dest_path)`
2. Check if file exists: if not, show error dialog "Installer file not found. Download again?" with a callback that resets banner to notification state (call `self._update_banner.show_notification()` so user can re-download). Return early.
3. Detect platform via `sys.platform`
4. **If Linux:** Show LinuxInstallInstructionsDialog directly (no confirmation needed, no app close):
   ```python
   LinuxInstallInstructionsDialog(self, self._installer_path, self._update_banner.version)
   ```
   Return (no app exit for Linux).
5. **If macOS/Windows:** Determine platform message:
   - macOS: `"Opening installer DMG..."`
   - Windows: `"Launching installer... Windows may show a security prompt."`
6. Show InstallConfirmDialog with `on_confirm=self._execute_install`

**Add `_execute_install(self)` method:**

Called when user confirms install in the dialog.

1. Determine platform message for status:
   - macOS: `"Opening installer DMG..."`
   - Windows: `"Launching installer..."`
2. Update banner to show status: `self._update_banner.complete_message.configure(text=platform_message)`
   - Or simpler: hide install button and update complete_message text
3. Try to launch installer:
   ```python
   try:
       launch_installer(self._installer_path)
   except RuntimeError as e:
       error_msg = f"Couldn't launch installer. File saved at: {self._installer_path}\n\n{e}"
       self._show_install_error(error_msg)
       return
   except Exception as e:
       error_msg = f"Couldn't launch installer. File saved at: {self._installer_path}\n\n{e}"
       self._show_install_error(error_msg)
       return
   ```
4. On success: Update banner message to "Installer launched. Closing app..."
5. Schedule app exit: `self.after(1500, self.destroy)` — 1.5 second delay per research recommendation

**Add `_show_install_error(self, error_msg: str)` method:**

Shows error with file path and retry button.

1. Show error dialog with the error message (includes file path per user decision)
2. Reset banner to complete state so user can retry: `self._update_banner.show_complete(str(self._installer_path))`

**Wire install callback in `_show_update_banner()`:**
- After creating banner, add: `self._update_banner.set_install_callback(self._on_install_now)`
- This is in addition to the existing `set_cancel_callback` call

- Modify the _on_retry_click and _on_dismiss_click in the banner to handle this — actually the banner already has retry_btn and dismiss_btn. For SHA256 errors, we want an additional "Download manually" option.
- Simplest approach: In the `download_failed` handler, if the error message contains "verification failed" or "hash", open the GitHub releases page in browser via `webbrowser.open(self._update_banner.release_url)` as an option. The banner's existing Retry button already re-triggers download. Add a comment noting this.
