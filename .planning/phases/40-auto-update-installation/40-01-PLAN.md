Add two functions to update_checker.py:

**1. `launch_installer(installer_path: Path, platform: str | None = None) -> str`**

Platform-specific installer launching. If `platform` is None, detect from `sys.platform`.

- **macOS (darwin):**
  - Run `hdiutil attach <path>` via `subprocess.run(capture_output=True, text=True, timeout=30)`
  - Parse stdout for mount point: split lines, find one containing `/Volumes/`, split on tab, take last field stripped
  - If mount point not found from parsing, try fallback: construct `/Volumes/{dmg_stem}` and check if it exists
  - If still not found, raise RuntimeError("Could not determine DMG mount point")
  - If hdiutil returncode != 0, raise RuntimeError with stderr
  - Open mount point in Finder via `subprocess.Popen(["open", mount_point])`
  - Return the mount point string
  - Leave quarantine attribute intact per research recommendation (notarized DMGs pass Gatekeeper)

- **Windows (win32):**
  - Launch exe via `subprocess.Popen([str(installer_path)], creationflags=subprocess.DETACHED_PROCESS | subprocess.CREATE_NEW_PROCESS_GROUP)`
  - Note: `DETACHED_PROCESS` and `CREATE_NEW_PROCESS_GROUP` are only available on Windows. Guard the `creationflags` kwarg behind `sys.platform == "win32"` check so the code doesn't reference undefined constants on other platforms.
  - Return empty string (no mount point concept)

- **Linux:**
  - Raise RuntimeError("Linux uses instructions dialog, not direct launch") — Linux flow is handled by the dialog, not this function

- **Error handling:**
  - Catch `subprocess.TimeoutExpired` → raise RuntimeError with "timed out" message
  - Catch `subprocess.CalledProcessError` → raise RuntimeError with stderr
  - Catch `FileNotFoundError` → raise RuntimeError with installer path in message
  - Catch `OSError` (permissions) → raise RuntimeError with path in message

**2. `cleanup_old_installers() -> int`**

Delete installer files from previous sessions. Called on app startup.

- Get `tempfile.gettempdir()` path
- Glob for patterns: `Job-Radar-v*-installer.dmg`, `Job-Radar-Setup-v*.exe`, `job-radar-v*-installer.tar.gz`
- For each match, try `Path.unlink()`, catch and log OSError (file may be in use)
- Return count of files successfully deleted
