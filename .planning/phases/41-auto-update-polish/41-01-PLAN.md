**GREEN phase — Implement methods:**

Add to `UpdateChecker` class in `job_radar/update_checker.py`:

1. **`skip_version(self, version: str) -> None`** — Store `None` as expiry in `suppressed_versions` dict (same pattern as `dismiss_version` but with `None` instead of timestamp). Uses `_load_config` / `_save_config` for atomic persistence.

2. **Modify `should_show_banner(self, version: str) -> bool`** — Before doing `datetime.fromisoformat(suppressed[version])`, check if expiry is `None`. If `None`, return `False` (permanent skip). Existing time-based logic stays for non-None values. The existing `except (ValueError, TypeError)` already handles edge cases.

3. **`is_version_skipped(self, version: str) -> bool`** — Check if version is in `suppressed_versions` with `None` expiry. Return `True` only for permanent skips, not time-based dismissals.

4. **`clear_skipped_versions(self) -> None`** — Load config, iterate `suppressed_versions`, remove entries where value is `None`. Preserve time-based dismissals (non-None values). Save config atomically.

5. **`get_skipped_versions(self) -> list[str]`** — Return list of version strings where `suppressed_versions[v]` is `None`.

6. **`fetch_release_notes(self, tag: str) -> str`** — Similar to `fetch_release_assets` but returns `data.get("body") or ""`. Use same URL pattern (`GITHUB_RELEASES_TAG_URL`), same headers, same timeout. Return empty string on any `RequestException`.

7. **`cache_release_notes(self, version: str, body: str) -> None`** — Store in `update_state.release_notes_cache.{version}` dict with keys `body` and `fetched_at` (ISO timestamp). Uses `_load_config` / `_save_config`.

8. **`get_cached_release_notes(self, version: str) -> str | None`** — Lookup in `release_notes_cache` dict. Return `body` if found, `None` if not cached.

Add module-level function:

9. **`extract_summary(markdown: str, max_bullets: int = 5) -> str`** — Parse markdown to extract first meaningful content:
   - If empty/whitespace: return "No release notes available for this version."
   - Split by `\n\n` into sections
   - Skip sections starting with `#` (headings) or `|` (tables)
   - If section has bullet lines (starts with `- `, `* `, `+ `): extract up to `max_bullets`, format with `•` prefix
   - Else if text section: return it (truncate at 400 chars with "..." if longer)
   - Fallback: return first 300 chars of raw markdown
