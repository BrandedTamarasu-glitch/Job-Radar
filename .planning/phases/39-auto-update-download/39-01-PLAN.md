  <name>Task 1: DownloadWorker class with streaming, cancellation, and SHA256 verification</name>
  <files>job_radar/gui/worker_thread.py, tests/test_download_worker.py</files>
  <action>
Add DownloadWorker class to worker_thread.py following the existing SearchWorker/MockSearchWorker pattern. Add imports at top: `import hashlib`, `import requests`, `from pathlib import Path`.

DownloadWorker.__init__ takes: result_queue (queue.Queue), stop_event (threading.Event), asset_url (str), asset_digest (str | None), dest_path (str).

DownloadWorker.run() method:
1. Call requests.get(self._asset_url, stream=True, timeout=30) with User-Agent header "Job-Radar/auto-update"
2. Call response.raise_for_status()
3. Read total_size from response.headers.get('content-length', 0), cast to int
4. Open self._dest_path in 'wb' mode, iterate response.iter_content(chunk_size=8192)
5. Before each chunk write, check self._stop_event.is_set() — if set, delete partial file with Path(self._dest_path).unlink(missing_ok=True), put ("download_cancelled",) on queue, return
6. After writing chunk, increment downloaded counter. Send progress update every ~100KB: `if downloaded % (100 * 1024) < 8192:` then put ("download_progress", downloaded, total_size) on queue
7. After loop completes, also send a final ("download_progress", total_size, total_size) to ensure 100% shown
8. If asset_digest is not None and not empty string: compute SHA256 of completed file using _compute_sha256() method. Extract expected hash (strip "sha256:" prefix if present). Compare. If mismatch: delete file, put ("download_failed", "Hash verification failed — file may be corrupted") on queue, return
9. If digest is None/empty: log warning "Asset has no digest field - skipping verification" and continue (per research Pitfall 3 — GitHub only provides digests for releases after June 2025)
10. Put ("download_complete", self._dest_path) on queue

DownloadWorker._compute_sha256(self, filepath: str) -> str: Read file in 4096-byte chunks, feed to hashlib.sha256(), return hexdigest().

DownloadWorker.cancel(self): Call self._stop_event.set().

Wrap entire run() body in try/except Exception — on exception, put ("download_failed", str(e)) on queue.

Add factory function create_download_worker(result_queue, asset_url, asset_digest, dest_path) -> tuple[DownloadWorker, threading.Thread]: Creates stop_event, DownloadWorker, and daemon Thread targeting worker.run. Returns (worker, thread). Caller must call thread.start().

For tests in test_download_worker.py:
- Test _compute_sha256 with a known file (write temp file with known content, verify hash matches precomputed value)
- Test that cancel() sets stop_event
- Test DownloadWorker.run() with mocked requests.get (use unittest.mock.patch): mock response with iter_content returning 3 chunks, verify ("download_progress", ...) and ("download_complete", ...) messages appear on queue, verify file written to disk with correct content
- Test cancellation mid-download: mock iter_content to yield chunks, set stop_event after first chunk, verify ("download_cancelled",) on queue and partial file deleted
- Test SHA256 mismatch: mock download then provide wrong digest, verify ("download_failed", ...) on queue with "Hash verification" in message
- Test null digest skips verification: provide asset_digest=None, verify ("download_complete", ...) on queue (no failure)
- Test network error: mock requests.get to raise requests.ConnectionError, verify ("download_failed", ...) on queue

3. Add standalone function get_platform_asset_pattern() -> str:
   - darwin: r"\.dmg$"
   - win32: r"\.exe$"  (matches NSIS installer)
   - linux (startswith): r"\.tar\.gz$"
   - else: raise RuntimeError(f"Unsupported platform: {sys.platform}")

4. Add method to UpdateChecker: fetch_release_assets(self, tag: str) -> list[dict]:
   - Build URL from GITHUB_RELEASES_TAG_URL.format(tag=tag)
   - GET with User-Agent header, timeout=REQUEST_TIMEOUT
   - Parse JSON, extract assets list
   - Return list of dicts with keys: name, browser_download_url, digest (may be None), size
   - On any RequestException, log error and return empty list

5. Add method to UpdateChecker: select_platform_asset(self, assets: list[dict]) -> dict | None:
   - Call get_platform_asset_pattern()
   - Iterate assets, re.search(pattern, asset['name'], re.IGNORECASE)
   - Return first match or None

6. Add method to UpdateChecker: get_installer_download_path(self, version: str) -> Path:

     - win32: f"Job-Radar-Setup-v{version}.exe"
     - linux: f"job-radar-v{version}-installer.tar.gz"
